Tampilan paragraf menyatukan kalimat yang berdekatan dan merapikan huruf kapital serta tanda baca. Koreksi di sini berlaku untuk salin dan TXT. File SRT dan VTT tetap per segmen agar cocok sebagai subtitle.

Gimana cara kerjanya?

Tidak ada server dan tidak ada file yang dikirim. Semuanya terjadi di browsermu.

01

Pilih dan jatuhkan

Pilih mode Video atau Audio, jatuhkan filenya, lalu atur bahasa dan ketelitian.

02

Suara diambil

Browser membuka file dan memadatkan suaranya jadi mono 16 kHz, format yang dipahami model.

03

Whisper menulis

Model AI Whisper dari OpenAI mendengarkan per bagian dan menulis teks beserta waktunya.

04

Rapikan dan bawa

Koreksi langsung di teks, cari kata, lalu salin atau unduh sebagai TXT, SRT, atau VTT.

Sering ditanyakan

Beberapa hal yang biasanya ingin diketahui sebelum mulai.

Apakah file saya dikirim ke internet?

Tidak. Video dan audio diproses di perangkatmu. Internet hanya dipakai untuk mengunduh model sekali, lalu disimpan di cache browser.

Kenapa pertama kali lama?

Model harus diunduh dulu (40 sampai 250 MB). Setelah itu langsung siap, dan prosesnya lebih cepat.

Bagaimana supaya hasilnya akurat?

Pilih bahasa yang tepat, pakai ketelitian "Teliti" untuk hasil final, dan gunakan rekaman yang jelas tanpa musik keras. Kata yang meleset bisa diklik dan diperbaiki langsung.

Prosesnya lambat atau gagal, kenapa?

Pakai Chrome atau Edge terbaru agar WebGPU aktif (jauh lebih cepat). Untuk file sangat panjang, coba ketelitian "Kilat" atau potong file dulu.

SRT dan VTT itu apa?

Format subtitle. Pakai di YouTube, CapCut, Premiere, atau pemutar video agar teks tampil di layar sesuai waktunya.

Dibuat dengan Whisper dan Transformers.js. Berjalan sepenuhnya di browser.
